# Source code

Lab này **không có code**. Toàn bộ bài làm là file Markdown và hình ảnh trong `report/`.

- File bắt đầu chạy: không có
- Cách chạy: không cần chạy
- Input: trải nghiệm thật của bạn, kết quả phỏng vấn/survey, tài liệu research
- Output: mỗi thành viên một file trong `report/individual/` (ví dụ `20241234_NguyenVanAn.md`), cộng `report/team/group_report.md`, `TEAM.md` và file phụ trong `report/assets/` — tất cả trên một repo nhóm
- File học viên được sửa: file báo cáo cá nhân của mình trong `report/individual/`, `report/team/group_report.md`, `TEAM.md`, thêm file vào `report/assets/`

Nếu nhóm muốn làm thử một prototype nhỏ (không bắt buộc, không tính điểm), có thể đặt ở đây kèm hướng dẫn chạy.
