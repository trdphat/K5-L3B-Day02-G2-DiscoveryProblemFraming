# Báo cáo nhóm

Báo cáo nhóm nằm tại:

```text
report/team/group_report.md
```

File này chứa phần **nhóm** của bài: CP3 → CP6. Nhóm làm chung **một bản** trên repo do nhóm trưởng fork. Không copy file này (hay `TEAM.md` ở root) sang repo cá nhân.

Báo cáo cá nhân của từng người **không** đặt ở đây, mà ở `report/individual/MSSV_HoTen.md`. Đóng góp của từng thành viên khai trong `TEAM.md`.
